# Contact

openEHR Assistant is a [Cadasto](https://www.cadasto.com/) product. Cadasto's
position, stated on its [About](https://www.cadasto.com/about-us/) page, is that
vendor-neutral open data platforms are vital as a foundation for a future-proof
healthcare IT system. Care data should be standardised, reusable, and available
when needed.

## Product issues

Bugs, questions about the server or the plugin, and pull requests belong in the
repository that owns the code. [Contributing](contributing.md) lists each
repository.
